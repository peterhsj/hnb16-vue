# IFSLC 金融服務中心

IFSLC - Vue 3 in Vite. (Type script)

## Recommended IDE Setup

[VSCode](https://code.visualstudio.com/)

[Nvm - Node 管理工具教學，一次裝好 Node 和對應 Npm 版本](https://www.casper.tw/development/2022/01/10/install-nvm/)

## Customize configuration

- 請先執行 Nvm 安裝 Node: 22.15.0 和 Npm: 11.7.0
- clone 專案後依下面步驟安裝

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
```

### Lint with [ESLint](https://eslint.org/)

```sh
npm run lint
```
